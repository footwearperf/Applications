Geocode stores

One-time admin tool. Looks up map coordinates for every store that doesn't have them yet, so the app can sort stores by nearest. You must be signed in as an admin.

—

Uses the free OpenStreetMap service, which allows about one lookup per second, so a few hundred stores takes roughly ten to fifteen minutes. You can stop and re-run any time; it only does the ones still missing. Keep this tab open and your screen awake while it runs.
